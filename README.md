# International Debt Statistics Analysis (SQL)

This project analyzes the **International Debt Statistics** dataset using SQL.

## Dataset
File: `International_debt dataset.csv`

Columns:
- `country_name` – Country name
- `country_code` – ISO country code
- `indicator_name` – Debt indicator description
- `indicator_code` – Debt indicator code
- `debt` – Amount in current US dollars

## Analysis Covered
The SQL analysis includes:
1. Understanding the dataset
2. Number of distinct countries
3. Distinct debt indicators
4. Total debt owed by countries
5. Country with the highest debt
6. Average debt across indicators
7. Highest principal repayments
8. Most common debt indicator
9. Other viable debt insights

## SQL File
All required calculation queries are provided in:
- `debt_analysis_queries.sql`

> Before running the queries, load the CSV into a table named `international_debt` with the same column names.
